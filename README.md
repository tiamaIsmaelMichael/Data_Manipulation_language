Projet Base de Données - Gestion Clients & Commandes
Description
Ce projet est une base de données simple pour gérer des clients, des produits et leurs commandes.

Tables Principales
Customer → Clients (Customer_id, customer_name, customer_Tel)

Product → Produits (Product_id, product_name, category, Price)

Orders → Commandes (Customer_id, Product_id, OrderDate, quantity, total_amount)
